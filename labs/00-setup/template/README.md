# ~/harness-lab/ 빈 템플릿

이 폴더를 본인 PC의 `~/harness-lab/`으로 복사하면 슬라이드 3쪽의 워크숍 폴더 구조가 그대로 준비된다.

```
~/harness-lab/
├── .claude/
│   ├── agents/        # 여기에 LAB의 *.md를 채워 넣는다
│   ├── skills/        # 여기에 LAB의 skill 패키지를 넣는다
│   ├── hooks/
│   └── settings.json  # 팀 모드 활성화 등
├── workspace/         # 실행 결과가 쌓이는 곳
└── samples/           # 입력 파일
```

각 LAB 폴더의 `.claude/`·`samples/`를 이 곳으로 합치거나, Lab 폴더에서 그대로 `claude`를 실행해도 된다.
