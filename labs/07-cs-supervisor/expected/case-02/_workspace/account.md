# Account 처리 결과

- 진단: account_locked
- 근거: 비밀번호 정상 입력에도 "잠긴 계정입니다" 메시지가 표시된다는 진술. 인증 코드 미수신은 잠금 상태와 결합된 흔한 증상.

## 복구 절차

1. 잠금 해제 요청 페이지에서 가입 이메일을 입력한다.
2. 스팸함과 광고함을 포함해 인증 메일을 다시 확인한다.
3. 메일이 5 분 이상 오지 않으면 SMS 인증으로 전환해 본인 확인을 진행한다.
4. 본인 확인 통과 후 안내 링크에서 비밀번호를 재설정한다.
5. 재설정 후 첫 로그인은 가입 시 사용한 기기·브라우저에서 시도한다.

## 추가 확인 필요

- 가입 이메일과 현재 수신 가능한 이메일이 동일한지 확인.
- 최근 30 일 이내 비밀번호 변경 이력 여부.
- SMS 인증 시 사용할 휴대전화 번호의 마지막 4 자리 확인.
