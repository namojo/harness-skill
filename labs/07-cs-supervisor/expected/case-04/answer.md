# 고객 응답

안녕하세요, 케이블 색상이 사진과 달라 환불을 요청하신 건 확인했습니다.

미개봉 상태의 단순 변심 환불은 구매 후 7 일 이내 정책상 처리 가능하여 환불이 승인되었습니다. 사진과 실물 색상이 디스플레이 환경에 따라 다르게 보일 수 있다는 안내가 충분하지 않았던 부분 송구합니다. 상세 페이지의 색상 정보 표기 방식부터 다시 점검하겠습니다.

회수 송장은 영업일 1 일 이내 발송드리며, 박스 미개봉 상태 확인 후 영업일 3 일 이내 결제 수단으로 환불이 완료됩니다. 왕복 배송비는 송장 안내 시 함께 안내드리겠습니다. 감사합니다.
